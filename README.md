# LibraryHub - Library Management System

A simple Library Management System where you can add names and store data in MongoDB Atlas with backend connection.

📍 Haridwar, Uttarakhand | MERN Stack Project

### 🌐 Live Website
**[https://libraryhub-js6u.onrender.com](https://libraryhub-js6u.onrender.com)**

### ✨ Features
- Add Name / Book Entry
- View all entries from database
- Delete entry
- Backend connected with MongoDB Atlas

### 🛠️ Tech Stack
- Frontend: React.js, HTML, CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Live: Render
